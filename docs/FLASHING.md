# Прошивка WolffBot

WolffBot прошивается прямо из браузера. Ни Arduino IDE, ни Python, ни ESP-IDF,
ни PlatformIO, ни Node.js, ни терминал не нужны.

---

## Что нужно

- Плата **Seeed Studio XIAO ESP32S3** с подключённым OLED-дисплеем
  SSD1306 128×64 (схема подключения — в [HARDWARE.md](HARDWARE.md#wiring)).
- USB-кабель **с передачей данных**. Кабели «только зарядка» не подойдут —
  плата просто не появится в списке портов.
- **Компьютер** с браузером **Chrome** или **Edge**.

> **Телефон или планшет не подойдёт.** Web Serial API не работает в Safari,
> Firefox, а также в браузерах на Android и iOS. Для прошивки используйте
> Chrome или Edge на компьютере.

---

## Прошивка через Web Flasher

1. Подключите плату к компьютеру USB-кабелем.
2. Откройте страницу Web Flasher (адрес — в
   [README](../README.md#web-flasher); при развёртывании на GitHub Pages это
   `https://<ваш-логин>.github.io/WolffBot-firmware/`).
3. Нажмите **«Подключить устройство»**.
4. Браузер покажет список последовательных портов. Выберите порт платы и
   нажмите «Подключиться».
5. Страница определит чип, ревизию, MAC-адрес и объём flash и покажет их.
   Если чип не ESP32-S3, появится предупреждение и прошивка **не начнётся**,
   пока вы явно её не подтвердите.
6. Нажмите **«ПРОШИТЬ»**.
7. Дождитесь надписи **«✓ WolffBot успешно установлен!»**, затем отключите USB.

Во время прошивки страница проходит этапы: Подготовка → Подключение к ESP32 →
Определение чипа → (Стирание flash) → Запись firmware → Проверка → Завершение.
Прогресс показывается полосой и процентами.

После записи каждого образа его MD5 сверяется с содержимым flash. Если хеш не
совпал, прошивка прерывается с ошибкой — «успешно» показывается только когда
проверка прошла.

## Настройки (по желанию)

В блоке **«Настройки прошивки»**:

- **Скорость порта** — по умолчанию 921600 (как в Arduino IDE для этой платы).
  Если связь нестабильна, выберите 115200.
- **Полностью стереть flash** — по умолчанию **выключено**. Так же поступает
  Arduino IDE: стираются и перезаписываются только те области, куда пишется
  прошивка. Включайте только если хотите удалить все пользовательские данные
  (NVS, SPIFFS) на плате.

## Если что-то пошло не так

| Что видно | Что делать |
| --- | --- |
| «Выбор порта отменён» | Нажмите «Подключить устройство» ещё раз и выберите порт |
| «Порт занят другой программой» | Закройте Arduino IDE, монитор порта, PlatformIO, любой терминал — и повторите |
| «ESP32 не отвечает и не вошёл в режим загрузчика» | Отключите USB, зажмите кнопку **BOOT (B)** на плате, подключите USB, отпустите BOOT, повторите. Порядок описан в [документации Seeed](https://wiki.seeedstudio.com/xiao_esp32s3_getting_started/) |
| «Истекло время ожидания» | Понизьте скорость порта до 115200 в настройках |
| «Связь с устройством потеряна» | Проверьте кабель (нужен кабель с данными) и переподключите плату |
| «Проверка записанных данных не прошла» | Повторите прошивку; при повторе — другой кабель или скорость 115200 |
| Порт платы вообще не появляется в списке | Кабель без передачи данных, либо плата не в режиме загрузчика — см. строку про BOOT выше |
| «Браузер не поддерживается» | Откройте страницу в Chrome или Edge на компьютере |

## Что именно записывается

Web Flasher ничего не компилирует и ничего не изменяет. Он записывает заранее
собранные бинарники по их подтверждённым адресам:

| Смещение | Файл | Размер |
| --- | --- | --- |
| `0x0` | `WolffBot-bootloader.bin` | 19 984 B |
| `0x8000` | `WolffBot-partitions.bin` | 3 072 B |
| `0xe000` | `boot_app0.bin` | 8 192 B |
| `0x10000` | `WolffBot-app.bin` | 408 864 B |

Параметры flash (`dio`, 80 МГц, 8 МБ) берутся из уже собранного образа
загрузчика — флешер передаёт esptool режим `keep` и не переписывает их, ровно
как это делает загрузка из Arduino IDE.

Адреса взяты из `build/flash_args`, который генерирует сам Arduino ESP32 core
(см. [BUILD.md](BUILD.md#flash-offsets)), а не подобраны вручную.

## Альтернатива: прошивка вручную через esptool

Если браузер использовать не хочется:

```bash
esptool --chip esp32s3 --port /dev/ttyACM0 --baud 921600 \
  write-flash --flash-mode keep --flash-freq keep --flash-size keep \
  0x0     WolffBot-bootloader.bin \
  0x8000  WolffBot-partitions.bin \
  0xe000  boot_app0.bin \
  0x10000 WolffBot-app.bin
```

или одним файлом:

```bash
esptool --chip esp32s3 --port /dev/ttyACM0 --baud 921600 \
  write-flash --flash-mode keep --flash-freq keep --flash-size keep \
  0x0 WolffBot-factory.bin
```

Бинарники лежат в `web-flasher/public/firmware/`.

## Как понять, что всё получилось

После прошивки и перезагрузки на OLED-дисплее проигрывается зацикленная
анимация из 90 кадров — та же самая, что в оригинальном DASAI Mochi. Никакого
вывода в serial-порт нет: оригинальная прошивка его не имеет, и WolffBot его
не добавляет.

Если дисплей остаётся пустым, а прошивка прошла успешно — проверьте
подключение I²C: SDA на `D4` (GPIO 5), SCL на `D5` (GPIO 6), питание 3V3 и GND.
